# 当前有效科研要求

依据：项目根目录两份 `20261004` 规划文件中用户确认的科研思路，以及用户对本轮工程基座和调研迁移的明确指令。当前指令优先于材料中的历史实施提示词。

## 建设目标与科研循环

建设能稳定产出顶会顶刊级方法的可运行 Harness。以真实问题、完整方法、推导和理论／实验结果验收科研质量；工程测试通过不能替代科研效果验收。

完整保留研究现状调研。调研、问题发现和方法设计反复迭代；贡献检查与验证贯穿方法设计。一个科研对象使用一套现行规则、状态和证据记录。

## 研究现状

领域地图应解释已有技术路线、作用机制、解决程度、假设、有效及失败条件、发展脉络、冲突和未解决线索。重要判断回查具体论文内容；区分作者明确结论、AI 归纳及待验证猜想。按具体知识缺口补充调研，更新同一份地图并保留历史证据和来源。

## 问题发现

保留两条路径：

1. 领域公认难题，可以来自单篇论文，优先核对多篇论文反映的共性问题。
2. 尚未被明确提出的共性 failure：从领域应用和第一性原理出发，结合多篇论文、文献冲突、解释缺口及边界条件主动发现。

用头脑风暴、质疑和苏格拉底式追问分析前提、反例、替代解释及研究价值。列出一个或多个问题候选，使人工看清痛点、文献依据、现有解决程度和价值；由人工选择后进入方法设计。

遇到本领域强 prior，继续追问它的假设、边界、failure 及仍值得研究的重要痛点。问题可随认知改进，但保持核心应用和关键研究问题；实质改变时说明原因，避免靠不断缩小范围削弱科研增量。

## 方法设计、贡献与验证

围绕人工选定的问题锚定可调整的具体技术主线。优先理解并复用、迁移、必要改造或融合成熟方法，需要时自行设计，形成可沿模型、变量、输入输出、算法和关键推导检查的完整技术路线。

区分文献的领域身份及其实际贡献覆盖程度。本领域强 prior 实质覆盖当前问题或拟议贡献时，更新地图，回到问题发现持续追问；仅有关联不足以触发回退。外域成熟方法是技术资源，判断其机制、输入输出、假设与目标任务是否匹配，不要求整个问题或根因同构。允许直接复用，不以改造量衡量贡献。

查新、理论检查、反例和必要试验应实际影响设计。区分选择设计的试验与支持最终贡献的独立验证；实际执行按已有授权、成本及试验条件处理。有依据、可解释、可验证且有实质收益的改进可以保留，同时控制无依据拼接。

RCA、原理搜索和机制竞争按适用性作为工具使用。具体方法设计无需先走强制 RCA／抽象 Principle 收敛链；其他创新形成模式后续逐步吸收。不要把经验中的想法数量、质疑轮数、固定评分或零检索命中变成科学判断。
